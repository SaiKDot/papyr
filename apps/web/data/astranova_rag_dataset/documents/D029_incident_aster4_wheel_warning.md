# Incident IR-028 — Aster-4 Reaction-Wheel Warning

- Document ID: D029_INCIDENT_ASTER4_WHEEL_WARNING
- Document type: incident report
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

On 4 October 2026, an Aster-4 reaction wheel remained at 4,670 rpm for 112 seconds, triggering the warning threshold of 4,600 rpm for 90 seconds. It did not exceed the hard operating limit of 4,800 rpm. Mission Operations reduced the commanded slew rate. No payload damage was observed. Owner: Lena Ortiz. Status: monitoring; not closed.
