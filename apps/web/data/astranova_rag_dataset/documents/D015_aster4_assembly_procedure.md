# Aster-4 Assembly and Inspection Procedure

- Document ID: D015_ASTER4_ASSEMBLY_PROCEDURE
- Document type: procedure
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

Before closing the Aster-4 avionics bay, technicians must verify connector seating, torque-mark integrity and cable clearance. The inspection requires two-person sign-off: one technician performs the check and a second independent inspector records verification.

The battery module is installed after the avionics harness inspection. The optical payload is installed only after the thermal interface inspection passes. Any non-conformance must be recorded in the build log and cleared by Quality before the unit proceeds.
