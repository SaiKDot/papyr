# Project Schedule and Budget Change Procedure

- Document ID: D039_PROJECT_CHANGE_PROCEDURE
- Document type: procedure or FAQ
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

A schedule change greater than five calendar days requires Customer Programmes approval. A budget increase greater than 5% of the approved baseline requires Finance approval. Forecast variance is not the same as an approved budget change. The approved baseline changes only when the authorised change is recorded.
