# Incident IR-031 — Orion Readiness Date Impact

- Document ID: D032_INCIDENT_ORION_SCHEDULE
- Document type: incident report
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

The repeat thermal-vacuum test moved Orion's launch-readiness date by seven calendar days, from 20 September to 27 September 2026. Customer Programmes approved the change on 2 September. The delay did not change the approved budget baseline. This incident is linked to IR-026. Status: closed.
