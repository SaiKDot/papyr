# Incident IR-030 — Battery Temperature Sensor Drift

- Document ID: D031_INCIDENT_BATTERY_SENSOR
- Document type: incident report
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

On 9 October 2026, an Aster-4 battery temperature sensor differed from the redundant sensor by 3.2 °C. The permitted difference is 1.0 °C. Charging was suspended as a precaution. The sensor was recalibrated and passed a 12-hour verification on 10 October. Owner: Tomas Reed. Status: closed.
