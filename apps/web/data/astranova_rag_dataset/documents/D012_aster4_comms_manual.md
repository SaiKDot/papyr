# Aster-4 Communications Manual

- Document ID: D012_ASTER4_COMMS_MANUAL
- Document type: operations manual
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

Aster-4 uses S-band for command and housekeeping telemetry and X-band for high-volume payload downlink.

The nominal X-band downlink rate is 180 Mbps under the standard ground-station configuration. If link quality falls below the approved threshold for two consecutive passes, Mission Operations must switch to the contingency S-band schedule and open a communications anomaly.
