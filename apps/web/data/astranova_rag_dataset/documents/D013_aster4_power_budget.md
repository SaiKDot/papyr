# Aster-4 Power Budget

- Document ID: D013_ASTER4_POWER_BUDGET
- Document type: engineering reference
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

The Aster-4 beginning-of-life solar array output is 620 W. The spacecraft bus and housekeeping load averages 210 W. Imaging payload load averages 145 W while imaging.

The battery planning capacity is 1.53 kWh, calculated as 85% of the 1.80 kWh beginning-of-life usable capacity. For conservative endurance calculations, use the planning capacity and subtract a 15% reserve from it before allocating energy to an extended activity.

This document is a planning reference; actual power availability must be checked against current telemetry before commanding.
