# Aster-2 Spacecraft Specification

- Document ID: D006_ASTER2_SPEC
- Document type: technical specification
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

Aster-2 is an earlier Earth-observation spacecraft.
- Nominal mass: 82 kg
- Battery usable capacity at beginning of life: 1.20 kWh
- Average payload power in imaging mode: 110 W
- Maximum operating temperature for the optical payload: 32 °C
- Communications: S-band
- Design life: 3 years

Aster-2 does not use the modular battery pack fitted to Aster-4.
