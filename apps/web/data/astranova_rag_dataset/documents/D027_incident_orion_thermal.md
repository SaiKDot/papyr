# Incident IR-026 — Orion Payload Overtemperature

- Document ID: D027_INCIDENT_ORION_THERMAL
- Document type: incident report
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

On 28 August 2026, the Orion Aster-4 optical payload reached 37 °C during thermal-vacuum testing. The current limit is 36 °C. The test was stopped. Root cause: insufficient thermal contact across the payload mounting interface due to shim tolerance. Corrective action: redesign the shim and repeat the test. The repeat passed at 31 °C on 1 September. Owner: Priya Sen. Status: closed 3 September 2026.
