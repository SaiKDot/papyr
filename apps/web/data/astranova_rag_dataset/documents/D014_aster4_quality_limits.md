# Aster-4 Quality and Reliability Limits

- Document ID: D014_ASTER4_QUALITY_LIMITS
- Document type: quality reference
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

The current Aster-4 reaction-wheel operating limit is 4,800 rpm, per Specification Revision 2. Any wheel speed above 4,600 rpm for more than 90 seconds must generate an operations warning.

The optical payload should normally operate at or below 30 °C. Imaging is suspended at 34 °C and prohibited at 36 °C. A temperature excursion must be logged in the spacecraft event record.
