# Spacecraft Anomaly Response Procedure

- Document ID: D038_ANOMALY_RESPONSE_PROCEDURE
- Document type: procedure or FAQ
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

When an anomaly is detected: (1) place the affected activity in a safe state if safety may be affected; (2) preserve telemetry; (3) notify Mission Operations; (4) open an incident record; (5) identify the applicable controlled specification revision; (6) document root cause and corrective action; (7) obtain Quality closure. Do not resume a prohibited activity without explicit Mission Operations authorisation.
