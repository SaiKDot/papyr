# Project Pelican — Power Review

- Document ID: D025_PELICAN_POWER_REVIEW
- Document type: project report
- Organisation: AstraNova Systems (fictional)
- Classification: Internal training dataset
- Status: Approved for RAG testing

The Pelican demonstration plan initially requested a continuous 90-minute imaging-plus-relay mode. Engineering rejected this combination because the combined load would exceed the approved conservative energy allocation. The approved plan separates imaging and relay activities and preserves the 15% reserve.
